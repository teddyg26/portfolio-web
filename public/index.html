About Me

Hello! I'm Ted, a Software Engineer trying to break into the industry. I enjoy cold winter nights with a warm stew, learning languages and linguistics (namely French), blasting music on a rainy drive, and cuddling with my cats.

I will graduate from Western Michigan University in 2027 with a Bachelor's Degree in Computer Science, and have an interest in low-level languages like C and Zig, as well as a broader curiosity for performant systems in code and how they operate with hardware. I also have a Minor in French, and did a summer study abroad in Québec City, Canada.

Pygame Wolfenstein

A semi-complete reimplementation of Wolfenstein 3D using pygame. Includes texture-mapping, depth-buffer occluded sprites, level-data processing, and a basic enemy AI with sound propagation detection and programmable spawn-flags and behaviors.

Zig CPU Scheduler Sim

A basic CPU scheduler simulator that handles several different scheduling routines along with I/O burst timings. This was a class project that I am fairly proud of as it gave good opportunity for modeling the CPU scheduler in code, along with CPU ticks and processes, and also gave room for practicing CLI programming.

GMTK Game Jam 2026

A turn-based tower-defense game prototype made in ~3 days for the 2026 GMTK Game Jam: "Count Down". The short time span meant that scope-creep could kill the project. Even knowing that, I still got ambitious, building a fully deterministic state-machine that tracks actions for rewind functionality and turn predictions that are displayed to the player. Playable in-browser here!

This Portfolio

While not the flashiest thing, I am fairly confident in the decisions I made for this one. Given that this is a portfolio website, a framework would be overkill. And, with LLMs able to spit out flashy next.js websites like it's nothing, I thought it best to show restraint. Built with vanilla HTML5/CSS3, Bun, and TailwindCSS. Deployed with Cloudflare Pages. It ain't much, but it's honest work!
