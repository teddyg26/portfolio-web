GMTK Game Jame 2026

A turn-based tower-defense game prototype made in ~3 days for the 2026 GMTK Game Jam: "Count Down". The short time span meant that scope-creep could kill the project. Even knowing that, I still got ambitious, building a fully deterministic state-machine that tracks actions for rewind functionality and turn predictions that are displayed to the player. Playable in-browser here!

This Portfolio

While not the flashiest thing, I am fairly confident in the decisions I made for this one. Given that this is a portfolio website, a framework would be overkill. And, with LLMs able to spit out flashy next.js websites like it's nothing, I thought it best to show restraint. Built with vanilla HTML5/CSS3, Bun, and TailwindCSS. Deployed with Cloudflare Pages.
