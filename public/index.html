GMTK Game Jame 2026

A turn-based tower-defense game prototype made in ~3 days for the 2026 GMTK Game Jam: "Count Down". The short time span meant that I had to be sure to not let scope-creep kill the project. Even with that being the case, I still got ambitious with building a full state-machine that tracks previous actions for rewind functionality and for strictly deterministic turn predictions that are displayed to the player. Playable in-browser on itch.io here!

This Portfolio

While not the flashiest thing, I am fairly confident in the decisions I made for this one. Given that this is a portfolio website, I limited the use of web technologies with the to not bloat the tech stack and minimize file sizes for snappy loading and browsing. With LLMs able to spit out colorful flashy next.js websites like it's nothing, I thought it best to do show restraint. Built with vanilla HTML5/CSS3, Bun, and TailwindCSS. Deployed with Cloudflare Pages, and setup to update when a push is made to the main branch of the Github repository. It ain't much, but it's honest work!
